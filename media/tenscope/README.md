# Tenscope design images

Source: Tenscope's "GPOD - Review" Figma board (Round 2 home + product page).
GPOD approved their use on the storefront on 2026-09-30 (the tour players are
approved GPOD users). Compressed here (JPEG q84 / optimised PNG, ≤2000px) and
imported into Shopify Files under the same filenames, so sections reference
them as `shopify://shop_images/<filename>`.

This folder is not a theme directory; Shopify ignores it on deploy.
