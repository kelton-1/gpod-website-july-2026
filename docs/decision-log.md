| 2026-08-11 | **Architecture: build parallel, never in place** (`docs/template-architecture.md`). Changes we want to learn from ship as *new* templates/sections beside the existing ones, never as overwrites — an overwritten template has no control arm and can only be believed, not tested. Verified against Intelligems' docs: Template Test variants must live in the *published* theme with the current template as control; **the home page cannot be template-tested at all** (Shopify blocks switching `index`), so home layout tests must run as Theme Tests — which matters most, since `/` is 51.8% of sessions. Governing rule for content work: **defects get fixed in the control, choices get tested as variants.** Instrumentation carries the test-group as an event property from day one.
